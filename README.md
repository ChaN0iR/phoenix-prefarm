# 菲歐妮 Phoenix 預刷材料追蹤

絕區零 3.3 菲歐妮預刷材料追蹤。單頁 HTML/CSS/JS，輸入持有數量，自動折算異常認證章、引燃晶片、喋血穢羽的進度。

- 使用：開啟頁面，在各材料欄位填入持有數量即可，進度即時更新；「清除」可全部歸零。
- 隱私：資料只存在你自己瀏覽器的 localStorage，不會上傳，沒有任何追蹤。
- 折算：3 個低階 = 1 個高階，掌控者 = 9 個初階。目標：異常認證章 370 初階等值、引燃晶片 2,500、喋血穢羽 60。
- 免責：依 3.3 公開資訊整理，數量以遊戲內為準。遊戲素材版權屬 HoYoverse。
